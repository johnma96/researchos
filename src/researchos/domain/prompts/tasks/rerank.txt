Your task is to reorder a list of documents based on how useful each one is for answering a specific query.
In addition, you must issue a verdict (true or false) on whether the documents, taken together, provide
enough context to adequately answer the query — not whether any single document is a perfect match, but
whether the information available is sufficient, or more information is needed.

Query: {query}

Documents (format: "doc_id": text):
```
{documents}
```

Return ONLY a JSON object with two keys: "ranked_ids" (a JSON array of document ID strings, sorted from
highest to lowest relevance) and "any_relevant" (a JSON boolean — your verdict on whether the documents
provide enough context to answer the query).

Example:
{{"ranked_ids": ["doc_id_1", "doc_id_2", "doc_id_3"], "any_relevant": true}}

Rules:
- Output must be valid JSON with exactly these two keys, nothing else — no explanation, no markdown.
- "ranked_ids" must contain exactly as many elements as there are documents above.
- No document ID may be repeated in "ranked_ids".
- "any_relevant" must be a JSON boolean (true or false), not a string.
